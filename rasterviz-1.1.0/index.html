Publication-quality raster maps directly inside QGIS

RasterViz provides a practical way to create publication-quality raster visualizations styled after rasterio.show().

Download

Features

Clean and efficient controls for every visualization need:

  • Stretch Control: Actual min–max, percentile, or manual
  • Discrete/Classified Rendering with per-class customization
  • RGB Composite three-band rendering
  • All rasterio-style colormaps
  • Customizable Pointed Colorbar
  • Grid Label Rotation & Coordinate Formats
  • Multi-map Layout Series with Live Updates
  • Global Export (PNG 300 DPI, SVG, TIFF, PDF)
